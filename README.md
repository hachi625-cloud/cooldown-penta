# クールダウン・ペンタ

小学3〜6年生向けのアンガーマネジメント練習アプリ（試作）。
「とまる → おちつく → かんがえる」を、ペンギンの「ペンタ」と一緒に練習します。

**公開ページ**: https://hachi625-cloud.github.io/cooldown-penta/

## できること
- **いま イライラ している（SOS）**：いかりの温度を選ぶ → 深呼吸・6秒カウント・ぐーぱー・離れる → これからどうするかを選ぶ
- **まなぶ**：1回5分のレッスン × 8ユニット（いかりって悪いもの？／温度計／からだのサイン／スイッチ／おちつく技／わざと？たまたま？／気持ちの伝え方／じぶんの作戦）
- **れんしゅう**：ゲーム「いかりんを しずめよう」、クイズ「わざと？ たまたま？」、おちつく技の練習
- **ふりかえり**：1分でつける「いかり日記」と、印刷できる「じぶん作戦カード」
- **おとなの方へ**：ホーム下部を長押しで表示。声かけのポイント、読み上げ設定、記録のまとめ

## 使い方
- ブラウザで公開ページを開くだけで使えます（Chromebook・iPad・スマホ対応）。
- 一度開くと、ネットにつながっていなくても動きます。
- 記録はその端末のブラウザの中だけに保存され、外部には送信されません。

## ローカルで動かす
```bash
python -m http.server 8765
```
http://localhost:8765 を開きます。

## 構成
ビルド不要の HTML / CSS / JavaScript です。
- `js/app.js` 画面と動き
- `js/data.js` 選択肢などのコンテンツ
- `js/lessons.js` 8ユニットのレッスン
- `js/art.js` イラスト（SVG）
- `docs/proposal.md` 企画提案と参考にした先行研究
