作成日: 2026-09-27
フォーカス: アンガーマネジメント（突発的にキレる／怒りをぶつける／クールダウン／振り返り）

## 1. 先行事例の調査まとめ

| 事例 | 概要 | 効果・知見 | アプリに取り込む要素 |
|---|---|---|---|
| 子ども・青年の怒りへのCBT メタ分析（Sukhodolsky et al. 2004） | 40研究の統合 | 平均効果量 d=0.67（中程度）。**スキル練習型・複合型は攻撃行動の減少に強く**、問題解決型は主観的な怒りの軽減に強い。感情教育のみは弱い（d=0.36） | 「知識」だけでなく**練習（ロールプレイ）**と**問題解決**を必ずセットにする |
| 学校ベースの怒り介入 メタ分析（Gansle 2005 / Candelaria 2012） | 学校での実施 | 怒り（.54）、外在化行動（.43）、社会的スキル（.34）に効果 | 学級・学校の端末で使える形にする |
| Coping Power（Lochman） | 小4〜5、子ども34回＋保護者16回 | 攻撃行動に中〜大の効果、1年後も学校での攻撃性が低下 | **保護者・教師向けパート**を用意（大人の関わりが効果を持続させる） |
| Second Step | 米国の代表的SEL教材 | 「**止まる → 落ち着く → 考える**」の3ステップで、強い感情を静めてから問題解決へ | クールダウン → 問題解決の順番をアプリの基本動線にする |
| RULER / Mood Meter（イェール大） | 感情の認識・命名・表現・調整 | 62校RCTで学校風土改善・いじめ／攻撃性減少 | 気持ちを「色×強さ」で選ぶUI（語彙が少ない子でも使える） |
| Zones of Regulation | 感情を4色ゾーンで表現 | 教師・子どもの評価は良好だが、RCTでは問題行動の有意な減少なし（エビデンスは混在） | 色分け表現は採用するが、**それだけに頼らない** |
| BrainPower（Hudley） | 「わざとだ」と決めつける傾向（敵意帰属バイアス）を修正する12回プログラム | **反応的攻撃（カッとなって手が出る）**の減少に効果 | 「わざと？たまたま？」判断トレーニング → “突発的にキレる”対策の中心 |
| Mightier（米国、7〜12歳） | 心拍バイオフィードバックのゲーム。心拍が上がるとゲームが難しくなり、落ち着くと進める | 72名RCTで6週間後に感情調整が改善、攻撃性・保護者ストレスも低下 | **ゲームで「イライラした状態から落ち着く」を安全に練習**させる（センサーなしでも擬似的に再現可能） |
| いかりやわらかレッスン（寺坂ら、日本） | 小3〜6、全5回×45分 | 内容は概ね妥当。攻撃性は一部低下、**もともと攻撃性の高い子ほど改善**。1か月後のスキル使用頻度も測定 | 日本の学校文化に合う言葉・場面設定。**スキル使用の記録**を効果指標にする |
| 日本アンガーマネジメント協会系の教材 | 「6秒待つ」「怒りの温度計」「べき」の書き換え、「人・自分・物を傷つけない」 | 学校で導入が進んでいる | 子どもにも先生にもなじみのある用語をそろえる |

### 調査から導いた「効くトレーニング」の7原則

1. **知識だけでなく練習させる**：講義型より、ロールプレイ・スキル練習型のほうが攻撃行動を減らす。
2. **落ち着くのが先、考えるのはその後**：怒りが高いときは考えられない。まず体を落ち着かせる → 次に選択。
3. **体のサインに気づかせる**：「顔が熱い」「こぶしを握る」など、爆発する前の手がかりに気づく力（内受容感覚）を育てる。
4. **「わざと？」の決めつけを揺さぶる**：突発的にキレる子は、あいまいな出来事を悪意と解釈しがち。別の解釈を考える練習をする。
5. **「少しイライラした状態」で練習する**：落ち着いているときの練習だけでは本番で使えない。ゲームで軽いフラストレーションを与え、そこから立て直す経験を積む。
6. **大人を巻き込む**：保護者・先生が同じ言葉で声をかけると、学んだことが実生活で使われやすくなる。
7. **振り返りで次につなげる**：「怒らなかったか」ではなく「気づけたか・技を試せたか」を評価する（我慢させる設計はNG）。

## 2. アプリ構成の提案

### 対象・利用環境
- **メイン対象：小学3〜6年**（先行研究の対象と一致）。小1〜2向けは文字を減らした「かんたんモード」で対応。
- **端末：GIGAスクール端末（Chromebook / iPad）と家庭のスマホ・タブレット** → ブラウザで動く **PWA（Webアプリ）** を推奨。インストール不要で、学校・家庭のどちらでも使える。

### 全体構成（5つのモード）

```
ホーム（今日の気持ちチェックイン：色×強さを1タップ）
 ├─ ① まなぶ     … 1回5〜10分のストーリー型レッスン（全8ユニット）
 ├─ ② れんしゅう … ゲーム・ロールプレイでスキルを体で覚える
 ├─ ③ いまつかう … イライラした“その瞬間”のクールダウンSOS
 ├─ ④ ふりかえり … いかり日記と「じぶん作戦カード」
 └─ ⑤ おとなモード（保護者・先生用、PINで切替）
```

### ① まなぶ：8ユニットのカリキュラム

| # | ユニット | ねらい | 主な中身 |
|---|---|---|---|
| 1 | いかりってなに？ | 怒りは悪くない。問題は「ぶつけ方」 | 3つのルール「人を傷つけない・自分を傷つけない・物をこわさない」 |
| 2 | いかりの温度計 | 怒りの強さを0〜10で測る | 自分の「何度で爆発しそうか」を知る |
| 3 | からだのサイン | 爆発前の手がかりに気づく | 体のイラストにサインをタップ（顔が熱い、こぶし、心臓ドキドキ…） |
| 4 | いかりのスイッチ | 自分の怒りのきっかけを知る | よくある場面（負ける、からかわれる、順番抜かし、注意される）＋「〜べき」に気づく |
| 5 | クールダウンの技 | 体を落ち着かせる技を身につける | 6秒カウント、深呼吸、ぐーぱー（筋弛緩）、その場を離れる、心の中の言葉 |
| 6 | わざと？たまたま？ | 決めつけを減らす | あいまいな場面を見て、ほかの理由を3つ考える |
| 7 | 気持ちの伝え方 | ぶつけずに言葉で伝える | 「わたしメッセージ」（〜されて、〜な気持ち。〜してほしい） |
| 8 | 作戦を立てよう | 問題解決と自分用プラン | 信号（赤：止まる → 黄：考える・選ぶ → 青：やってみる）、「じぶん作戦カード」完成 |

各ユニットは **「アニメ／マンガで場面を見る → 選択肢を選ぶ → 結果を見る → ミニ練習」** の形にする（見るだけで終わらせない）。

### ② れんしゅう：体で覚えるトレーニング

- **クールダウン・ゲーム（Mightier型の考え方）**：ブロック崩し等のミニゲーム中に、わざと邪魔が入ったり理不尽な展開が起きる。画面の「イライラメーター」が上がったら、呼吸ガイドに合わせてゆっくり息をする（長押しで吸う・離して吐く）とメーターが下がり、ゲームが再開できる。 → 「イラッとした → 落ち着く → 立て直す」の成功体験を積む。
  - 将来の拡張：スマートウォッチや端末カメラでの心拍計測。
- **わざと？たまたま？クイズ**：「ボールが当たった」「笑い声が聞こえた」などの場面で、相手の表情・状況をよく見て判断。いくつもの見方ができることを学ぶ。
- **どうする？ロールプレイ**：場面に対して行動を選び、その後どうなったかを分岐ストーリーで体験（「たたく」を選んでも罰は与えず、結果を見て別の道を試せる）。
- **伝え方れんしゅう**：わたしメッセージを穴埋めで作り、音声で言ってみる（録音は端末内だけに保存）。

### ③ いまつかう：クールダウンSOS（最重要動線）

ホームからワンタップ、**3ステップ以内で完結**させる。

1. **とまる**：「いま何度？」温度計をスライド
2. **おちつく**：その子が選んだ得意技を大きく表示（呼吸アニメ／6秒カウント／ぐーぱー／「その場を離れていいよ」）
3. **かんがえる**：温度が下がったら「どうしたい？」の選択肢（先生に言う／あとで話す／わたしメッセージで伝える／今はそっとしておく）

※ 学校では授業中に端末を開けないこともあるため、**印刷できる「じぶん作戦カード」**（筆箱に入るサイズ）も出せるようにする。

### ④ ふりかえり：いかり日記

落ち着いたあと（下校前や寝る前）に、選択式で1分ほどで記録。

- いつ・どこで／何があった（場面アイコン）
- 何度まで上がった？／体のサインは？
- 何をした？（使った技・とった行動）
- どうなった？（顔アイコン）
- 次はどうする？

**評価の仕方**：ポイントやスタンプは「怒らなかった」ではなく、**「気づけた」「技を試せた」「記録した」**に与える。週に1回「今週のじぶん」をグラフで振り返る（どのスイッチが多いか、効いた技はどれか）。

### ⑤ おとなモード（保護者・先生向け）

- 子どもが学んでいる言葉と技の説明（大人も同じ言葉で声をかけられるように）
- 怒っている子への関わり方のコツ（まず落ち着く手伝い → 落ち着いてから話を聞く、責めずに振り返る）
- 子どもが**共有を許可した記録だけ**を見られる。自由記述は親には見せないなど、子どもの安心感を守る
- 先生向け：学級で使う授業用スライド・進め方の案

## 2.5 決定事項（2026-09-27）と、理解力・意欲が低めの子向けの設計方針

- 利用場面：**学校メイン、家庭でも使える**形（ブラウザで動くWebアプリ、ビルド不要）
- 対象：**小3〜6年**。ただし標準より理解力・学習意欲が低い子を想定する

| 方針 | 具体策（試作に反映済み） |
|---|---|
| 読まなくても分かる | ひらがな＋わかちがき、絵文字アイコン中心、全画面に🔊読み上げボタン、UDフォント |
| 1画面1問 | 質問は1つずつ、選択肢は大きなボタン、自由記述なし |
| 短く終わる | レッスン5分・日記1分（6問）・SOS 3ステップ。進み具合を●で表示 |
| 失敗させない | クイズで間違えても責めずに次へ進める。「たたいた」を選んでも叱らない |
| すぐごほうび | 操作するたびにシール＋効果音、たまるとランク（クールのたまご→マスター） |
| 体で覚える | 呼吸の円アニメ、6秒カウント、ぐーぱー、ゲーム（長押しで息を吸う） |
| 熱くなっている時は選ばせない | SOSは温度を選ぶだけで、いつもの技（日記で決めた「次の作戦」）が自動で始まる |
| 教室への配慮 | 読み上げは初期設定オフ（大人の画面でオン）、クールダウン場所を大人が設定 |

## 3. 設計で気をつけること

- **治療ではない**ことを明記する。暴力が深刻な場合や、自分を傷つけるような記述・虐待が疑われる内容には、相談窓口（24時間子供SOSダイヤル等）への案内を出す。
- **我慢・抑え込みを奨励しない**：怒りは自然な感情。目標は「うまく出す」こと。
- **罰・減点をしない**：失敗も学びとして扱う。
- **個人情報**：初期版は端末内保存のみ（アカウント不要）。クラウド共有は保護者同意の仕組みができてから。
- **読みやすさ**：ふりがな、音声読み上げ、アイコン中心、短い文。発達特性のある子にも使いやすく。
- **1回が短い**：レッスン5〜10分、日記1分、SOS 1分以内。

## 4. 効果の測り方（アプリ内で自動集計）

- 事前・事後の簡単な自己評価（怒りの頻度・強さ、「落ち着く自信」）
- スキル使用の回数（SOSの使用、日記に記録された技）
- 爆発前に気づけた回数の推移
- 保護者・先生による簡単な行動評価（任意）

## 5. 開発ステップ案

| フェーズ | 内容 |
|---|---|
| MVP | ホーム（気持ちチェックイン）、ユニット1〜3・5、クールダウンSOS、いかり日記、端末内保存 |
| v1 | 全8ユニット、クールダウン・ゲーム、わざと？たまたま？クイズ、じぶん作戦カード印刷、週次グラフ |
| v2 | おとなモード、学級向け教材、データ共有、心拍連携などの拡張 |

技術：素のHTML/CSS/JavaScriptで作るPWA（ビルド不要。学校端末で開発ツールなしに配布・更新しやすい）。データはlocalStorageに保存し、Service Workerでオフラインでも動かす。規模が大きくなったらReact等への移行を検討。

### 試作 v0.1 の実装状況
- ✅ ホーム（気持ちチェックイン）、SOS（とまる→おちつく→かんがえる、技4種）、いかり日記＋集計、シール帳
- ✅ まなぶ：ユニット1〜8すべて（v0.2で4〜8を追加。7は「わたしメッセージ」組み立て、8は印刷できる「じぶん作戦カード」）
- ✅ イラスト（v0.2）：ペンタ（表情6種）、いかりん（怒りの強さ5段階）、信号、スイッチをSVGで作成。温度計・ゲーム・レッスンに使用。選択肢のアイコンは絵文字のまま
- ✅ れんしゅう：いかりんを しずめよう（ゲーム）、わざと？たまたま？（5問）、落ち着く技の練習
- ✅ 大人の画面（長押しで開く）：説明、声かけのポイント、読み上げ設定、クールダウン場所、記録のまとめ、データ消去
